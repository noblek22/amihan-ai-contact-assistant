# Amihan AI Contact Assistant

AI-powered relationship and contact management platform built with FastAPI.

## Features

- User authentication
- Session management
- Role-based access control (RBAC)
- SQLite database
- Contact CRUD
- Search + filtering
- Pagination
- Analytics endpoints
- AI-style messaging assistant
- Persistent AI memory

## Tech Stack

- Python
- FastAPI
- SQLite
- bcrypt
- HTML/CSS/JavaScript
